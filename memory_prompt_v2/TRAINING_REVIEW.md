# 正式训练前的问题清单

本清单区分实际观察、v1里的结构性风险和建议。来源为本轮500题导出、此前case0123日志、summary和算法v1；未声称审计了你本地所有最新源码。

## A. Gate是什么

Gate是候选问答质量检查，不是训练模型，也不判断当前M一定缺信息。原v1要求：E能支持答案、无记忆defender答不对、用户会问、格式和证据合法。后来的full模式还增加全库宽检索筛查。模型/网络错误应返回ERROR，不能当reject或奖励负例。

应明确三层：

```text
candidate(q,a,E) → gate（题目是否可用）
                → defect(M,q,E)（是否暴露当前M的缺陷）
                → Q / patch（符合两者后才修复）
```

accepted候选集合V不等于Mistake Book Q。当前批量出题是数据/接口预验证，不是原设定中的完整对抗训练。

## C. 问答语义之外的训练风险

1. closed-book单次猜对不代表不需要记忆，猜错也不证明题有价值。保留这个门槛，但分类型审计，尤其个性化建议不能“泛泛建议碰巧满足”就判为已使用用户记忆。API异常不能混成非closed-book。
2. v1缺陷类别只有来源missing和unretrievable，遗漏“来源已引用、条目已命中，但关键细节被压掉”的lossy情形。需按目标事实/可见memory文本诊断，不用prov覆盖替代。
3. `ans(M⊕E,q)=1`仍依赖同一检索器。原文虽补入但仍检不齐时，可能错误排除本可通过整合主题卡片修复的问题。可加“直接给E是否可答”的诊断分支，但最终修复必须回到真实检索路径验证。
4. patch修复新题不能破坏历史Q。逐字ADD(E)也不保证top-k取到，且长E与条目长度限制冲突；回退后仍需重测与回归。
5. Refine只保住有限Q，并非证明所有未见问题仍可答。faith只验证不造假，不证明所有事实都保留；部署最终M仍需留出问题、不同reader与准确率–体积曲线。
6. attacker奖励若主要由gate接受率驱动，会倾向容易、重复、局部的题。KL只是约束相对参考策略偏移，并不保证用户价值或全局覆盖；同E去重还可能误伤不同属性。
7. v1中的N=4次采样与当前“每包最多4题”不是同一预算；GRPO每状态G=8也不能混为题数。训练前固定采样单位、每轮tokens、模型请求和有效样本成本。
8. 48k字符预算不等于16k attacker tokens；正式小模型使用其自身tokenizer，计算system+payload+输出余量。新的结构化输入有额外JSON开销。
9. 人工看过的500题包含相近正负变体。按共享历史分组去重并隔离train/dev/test，避免同一原文换一道问题就跨分区。事后拆分不恢复已暴露的prompt测试独立性。

## D. 本轮题库直接提示的任务模式

- 多session不只是“综合聊过的主题”：计数、加减、比例、平均、去重、排除项和跨事件指代是主要结构。
- 时间问题同时存在event ordering、elapsed interval、duration与temporal lookup；不能只问日期。
- 教育/工作等多阶段经历的累计时长需要明确间断和重叠，不把首尾跨度等同累计时长。
- 旧值和当前值都可能被问；新更新不能自动证明旧事实没有价值。
- assistant回忆可能涉及本来不真实的创作或旧回复中的事实陈述。记忆评测关心当时说了什么，与外部事实真实性是两种标准。
- preference需要建议/决策的个性化约束，不是把事实抽取题改个type。
- abstention是缺失信息边界，不是局部pack没检出就能生成的“答案为零”题；需独立的全史负例验证协议。

## E. 建议的消融顺序（未执行）

- A0：当前旧generator/旧gate，修复SSL并补完错误，作为基线。
- A1：英文v2 generator + 中性ID/seed视图，旧gate不变。
- A2：在A1上启用英文gate三项及support对齐；reader benchmark的全局grade保持不变。
- A3：在固定总4题/同等预算下增加混合槽位或有账本的重复审计。

比较原始问题的证据并集、通过gate的原始E并集、通过gate的最终E并集；同时记录有效率、事实/题目重复、假拒绝、采样成本。最终训练收益必须看M是否保住新问题能力和target准确率，不能只看coverage。
